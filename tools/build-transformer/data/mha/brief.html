One attention op is not enough — a transformer runs h of them in parallel on slices of the feature axis, then concatenates and projects. The whole exercise is the bookkeeping: split the model dimension into heads, attend, merge back.

q = x Wq⊤                                (b, n, d_model)
q = rearrange(q, "b n (h d) -> b h n d")   split into heads
o = Attn(q, k, v, mask)                    (b, h, n, d_head)
o = rearrange(o, "b h n d -> b n (h d)")   merge heads
y = o Wo⊤
  • x — (b, n, d_model)
  • Wq, Wk, Wv, Wo — (d_model, d_model)
  • num_heads — divides d_model; d_head = d_model // num_heads
  • mask — boolean (n, n) or None, shared by all heads

Return (b, n, d_model). softmax and attention(Q, K, V, mask) are already defined for you.

Hint

Head i owns the contiguous slice [i*d_head : (i+1)*d_head] of the projected features — that is exactly what (h d) means in the pattern above, and it is why the merge must be the exact inverse. The mask needs a broadcastable head axis: mask[None, None] or rearrange(mask, "q k -> 1 1 q k").
