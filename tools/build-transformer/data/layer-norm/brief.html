Normalise each token vector on its own — across features, never across the batch — then give the network back a learnable scale and shift.

$$y = \gamma \odot \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta$$

  • x — (..., d); $\mu$ and $\sigma^2$ are taken over the last axis
  • gamma, beta — (d,), broadcast over the leading axes
  • eps — added inside the square root, default 1e-5

Use the biased variance (divide by $d$, not $d-1$) — that is what np.var does by default, and what every framework uses here.

Hint

keepdims=True on the mean and variance keeps the broadcast aligned. A constant input row must not produce NaN — that is what eps is for.
