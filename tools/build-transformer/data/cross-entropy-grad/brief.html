The gradient interviews love, because the algebra collapses so cleanly. For one token with logits $z$ and target $y$, the loss is $\operatorname{logsumexp}(z) - z_y$, and differentiating gives

$$\frac{\partial \mathcal{L}}{\partial z_j} = \frac{1}{N}\Bigl(\operatorname{softmax}(z)_j - \mathbb{1}[j = y]\Bigr)$$

— the predicted distribution minus the one-hot target, divided by $N$, the total number of tokens (all leading axes), because the forward loss is a mean.

  • logits — (..., vocab_size)
  • targets — integer array of shape (...)

Return an array shaped like logits. The softmax inside must be the stable, shifted kind — the tests feed logits in the hundreds.

Hint

Build the one-hot by scattering into zeros: np.put_along_axis(onehot, targets[..., None], 1.0, axis=-1). $N$ is targets.size. A sanity check the tests also run: every token's gradient row sums to $0$, because softmax sums to 1 and the one-hot subtracts exactly 1.
