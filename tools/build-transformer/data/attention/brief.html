The operation the whole architecture is named after. Everything else in the block is plumbing around this.

$$\operatorname{Attn}(Q, K, V) = \operatorname{softmax}\!\left(\frac{Q K^\top}{\sqrt{d_k}} + M\right) V$$

  • Q — (..., n_q, d_k), any leading axes (batch, heads, …)
  • K — (..., n_k, d_k)
  • V — (..., n_k, d_v)
  • mask — boolean, broadcastable to (..., n_q, n_k), or None. True means "may attend": $M$ is $0$ where the mask is True and $-\infty$ where it is False, so blocked positions get exactly zero weight.

Return (..., n_q, d_v). A stable softmax is already defined for you.

Hint

Divide by $\sqrt{d_k}$, not $d_k$. Apply the mask by setting the blocked scores to -np.inf before the softmax — np.where(mask, scores, -np.inf). With einops: einsum(Q, K, "... q d, ... k d -> ... q k").
