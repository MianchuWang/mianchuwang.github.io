The loss every language model is trained on. Going through softmax and then log is the classic beginner bug: it overflows for large logits and loses precision for small probabilities. Fold the two together instead.

$$\mathcal{L} = \operatorname*{mean}_{\text{tokens}}\;\Bigl[\operatorname{logsumexp}(z) - z_{\text{target}}\Bigr]$$

  • logits — (..., vocab_size), unnormalised scores
  • targets — integer array of shape (...), the correct index per token

Return a single float: the mean over all leading axes (batch, sequence, …).

Hint

Subtract the row max first — it cancels out of the difference above. np.take_along_axis(z, targets[..., None], axis=-1) picks the target logits without a loop, and works for any number of batch axes.
