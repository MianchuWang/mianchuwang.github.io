A single bad batch can produce a gradient large enough to wreck a run. Clipping bounds the global norm — all parameter tensors treated as one long vector — so the update direction is preserved and only its length is capped.

$$\lVert g\rVert = \sqrt{\sum_{\text{tensors}}\;\sum_{\text{elements}} g^2},\qquad \text{if } \lVert g\rVert > c:\;\; g \leftarrow g\cdot\frac{c}{\lVert g\rVert + \epsilon}$$

  • grads — a list of arrays with different shapes
  • max_norm — $c$, the cap on the global L2 norm
  • eps — guards the division, default 1e-6

Return a new list of arrays in the same order and shapes. If the norm is already within the cap, leave the gradients as they are.

Hint

One norm for the whole list, not one per tensor — sum((g**2).sum() for g in grads). Every tensor is then scaled by the same factor, so the direction of the concatenated gradient never changes.
