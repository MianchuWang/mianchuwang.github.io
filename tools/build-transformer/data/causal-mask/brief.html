A decoder may not look ahead. The square version is one np.tril, but the interesting case is decoding with a KV cache, where you feed n_q new queries against n_k cached keys — the diagonal is then offset.

Treat query $i$ as the token at absolute position $n_k - n_q + i$, so it may attend to every key $j \le n_k - n_q + i$.

  • n_q, n_k — number of queries and keys, with n_q ≤ n_k

Return a boolean array of shape (n_q, n_k): True where attention is allowed. With n_q == n_k this is the familiar lower triangle; with n_q == 1 (one new token against a full cache) every entry is True.

Hint

np.tril takes a k offset, and it accepts non-square shapes. Or build it from index arrays: np.arange(n_k)[None, :] <= (n_k - n_q + np.arange(n_q))[:, None]. Make sure the dtype is bool.
