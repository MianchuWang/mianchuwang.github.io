Why decoding one token costs $O(n)$ instead of $O(n^2)$: keys and values for the past are computed once and cached; each new token projects only itself, appends, and attends over the whole cache. This is the loop every inference server runs.

One decode step, single head, no output projection:

  • Project the new token: $q = x W_q^\top$, $k = x W_k^\top$, $v = x W_v^\top$ (one position per batch element).
  • Append $k$ and $v$ to their caches along the time axis.
  • Attend $q$ over the full updated cache. No mask needed — the single query is the newest position, so it may see everything, itself included.

Return (out, k_cache_new, v_cache_new). The signature enforces the cache growth: in comes "b t d_k", out goes "b t+1 d_k". The caches must not be mutated in place. The empty-cache case (t = 0, the first token) must work.

Available: softmax and attention(Q, K, V, mask=None). The defining property, which the tests check: decoding a sequence one token at a time must reproduce full causal attention over that sequence exactly.

Hint

np.concatenate([k_cache, k[:, None, :]], axis=1) grows the cache; attention(q[:, None, :], K, V)[:, 0] treats the single query as a length-1 sequence. If the one-by-one-equals-causal test fails but shapes pass, you probably attended over the old cache, excluding the new token itself.
