Now assemble one decoder layer. Every piece is already written for you — the exercise is the wiring, which is where most from-scratch implementations actually go wrong: pre-norm vs post-norm, and what exactly the residual adds to.

h = x + MHA(RMSNorm(x, g1), Wq, Wk, Wv, Wo, num_heads, causal mask)
y = h + SwiGLU(RMSNorm(h, g2), W1, W2, W3)

Note that the second residual branches from h, not from x, and that the norms sit inside the residual branches — the pre-norm arrangement that keeps deep stacks trainable.

  • x — (b, n, d_model)
  • p — dict with g1, Wq, Wk, Wv, Wo, g2, W1, W2, W3
  • num_heads — passed straight through to attention

Attention must be causal: build the mask with causal_mask(n, n).

Available: rms_norm(x, gamma, eps=1e-6), softmax, attention, multihead_attention(x, Wq, Wk, Wv, Wo, num_heads, mask=None), swiglu(x, W1, W2, W3), causal_mask(n_q, n_k).

Hint

Four lines. If the test "all-zero weights leave x untouched" fails, a residual is missing; if "matches the reference wiring" fails but the shapes are right, you likely normalised the residual stream itself instead of only the branch.
