Turn scores into a distribution along one axis. The naive version overflows the moment a logit reaches ~700, which is why every real implementation subtracts the max first — softmax is invariant to a constant shift, so this changes nothing but the arithmetic.

$$\operatorname{softmax}(x)_i = \frac{e^{\,x_i - \max_j x_j}}{\sum_k e^{\,x_k - \max_j x_j}}$$

  • x — any shape
  • axis — the axis to normalise over, default -1

Return an array of the same shape whose slices along axis sum to 1.

Hint

keepdims=True on both the max and the sum keeps the broadcast working for any axis. Handle a negative axis for free by never converting it.
