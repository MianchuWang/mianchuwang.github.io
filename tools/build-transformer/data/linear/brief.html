Every projection in a transformer is this one operation, so the shape reflex is worth drilling: the map applies to the last axis and leaves any leading batch axes alone.

$$y = x W^\top + b$$

  • x — (..., d_in), any number of leading axes (or none at all)
  • W — (d_out, d_in), PyTorch's convention: one row per output unit
  • b — (d_out,), or None for a bias-free layer

Return an array of shape (..., d_out).

Hint

einsum(x, W, "... d_in, d_out d_in -> ... d_out") handles the leading axes for you. In plain numpy, x @ W.T broadcasts the same way.
